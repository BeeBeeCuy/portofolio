## Teknologi

Situs statis tanpa dependensi: HTML, CSS, dan JavaScript murni. Siap di-deploy ke Vercel / GitHub Pages / hosting statis apa pun.

## Menjalankan secara lokal

Buka `index.html` di peramban, atau jalankan server statis sederhana:

```bash
python3 -m http.server 8000
```

Lalu kunjungi http://localhost:8000.
